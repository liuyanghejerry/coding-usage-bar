## Data Sources

Tibo Reset tracking uses the free, keyless public API of [codex-resets.com](https://codex-resets.com). "Tibo Reset" is the community name for the Codex quota resets announced by Thibault Sottiaux. Wherever that data is displayed, Coding Usage Bar credits the source with a visible `Data from codex-resets.com` link, as requested by the service. The upstream watch data is an AI-classified forecast, not an official OpenAI commitment.
